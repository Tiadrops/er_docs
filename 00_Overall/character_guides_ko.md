## 윌리엄

**역할:** 탱커 / 1선 이니시에이터
**장인초대석:** 25.02.12~13, 둔둔빵줘라

### 집단전 역할
- 1선에서 이니시에이트. 궁극기로 적을 구속한 후 아군이 따라오기를 기다림
- CC 체인이 핵심. W → E → R 순서로 적을 최대한 오래 잡아둠
- 아군 딜러 보호도 가능. 적 어쌔신이 3선에 진입하면 돌아가서 CC

### 교전 포인트
- 진입 타이밍: 적 핵심 스킬 사용 후 진입이 가장 안전
- 궁극기가 없으면 무리한 이니시 금지. 기다리는 것도 전략
- 내구도를 과신하지 말 것. 아무리 탱커여도 3명에게 집중당하면 빠르게 녹음

### 실수 패턴
- 너무 깊이 들어가서 아군이 따라올 수 없음
- 궁극기 없이 진입 → CC 없으면 그냥 맞고 죽음
- 아군 딜러를 무시하고 계속 앞으로만 감

## 셀린

**역할:** 서포터 / 3선
**장인초대석:** 25.02.15, 송하랑

### 집단전 역할
- 3선에서 아군 딜러를 보호하면서 힐과 쉴드 제공
- CC로 적 진입을 방해. 적 브루저/어쌔신이 아군 딜러를 노리면 즉시 CC

### 교전 포인트
- 힐/쉴드 타이밍이 모든 것. 0.5초 차이로 아군이 살거나 죽음
- 궁극기는 "살리기"용으로 아끼는 것이 기본. 공격용으로 먼저 쓰지 말 것
- 포지셔닝: 항상 딜러 가까이 위치. 딜러와 멀어지면 서포터의 가치가 0

### 실수 패턴
- 딜러를 두고 앞으로 나감
- 힐을 너무 빨리 사용 (적이 본격 교전 전에 힐 다 소진)
- CC를 허공에 사용

## 타지아

**역할:** 원거리 딜러 / 3선
**장인초대석:** 25.02.18, Cherish

### 집단전 역할
- 안전한 거리에서 지속 딜. 가장 가까운 안전한 대상을 공격
- 생존이 곧 딜. "죽은 딜러의 DPS는 0"

### 교전 포인트
- 사거리 관리가 핵심. 적의 진입 사거리 밖에서 딜
- 궁극기로 적 이니시를 끊거나, 도주하는 적을 마무리
- 포지셔닝: 1선 뒤에 항상 위치. 전방으로 나서지 않음

### 실수 패턴
- 킬욕으로 사거리 안에 들어감 → 잡힘
- 탱커를 때리는데 시간 소비 (뒤에 딜러/서포터가 있으면 그쪽을 노려야 할 때도)
- 아군이 교전 중인데 너무 멀리서 구경

## 캐시

**역할:** 암기 딜러 / 2~3선
**장인초대석:** 25.02.26, 캐시맨

### 집단전 역할
- 원거리 견제 + 순간 폭딜. 암기 사거리를 활용한 포크 플레이
- 적 체력을 깎아놓은 후 아군이 마무리

### 교전 포인트
- 풀콤보 적중 시 한 명 증발 가능. "콤보 정확도 = 캐시의 가치"
- 콤보 실패 시 무리하지 말고 빠져서 쿨타임 기다리기
- 위치 선점이 중요. 교전 시작 전에 좋은 각도를 잡아야 함

### 실수 패턴
- 콤보 빗나간 후에도 근접전 시도 → 내구도 부족으로 사망
- 팀과 너무 떨어져서 플레이 → 합류가 늦음
- 시야 없이 무빙 → 적 어쌔신에게 잡힘

## 나타폰

**역할:** 브루저 / 1~2선
**장인초대석:** 25.04.11, 엄빠TV

### 집단전 역할
- 쌍절곤의 CC와 데미지로 전방에서 싸움. 적을 구속하면서 딜
- 이니시도 가능하지만, 1선 탱커가 있으면 2선에서 후속 투입이 더 효율적

### 교전 포인트
- CC 연계가 핵심. 스킬 순서를 미리 계획해서 적을 최대한 오래 잡아둠
- 궁극기는 여러 명을 맞출 수 있는 타이밍에 사용
- 내구도와 딜의 균형: 상황에 따라 탱키하게 빌드하거나 딜 빌드 전환

### 실수 패턴
- CC를 한 명에게만 집중 → 나머지 적이 자유롭게 딜
- 궁극기를 1명에게만 사용 → 가치 낭비
- 후방을 무시하고 전방만 보다가 아군 딜러가 잡힘

## 루크

**역할:** 탱커 / 1선 이니시에이터
**장인초대석:** 25.04.16, Karmis

### 집단전 역할
- 강력한 이니시에이트. 궁극기로 적 핵심을 잡아서 교전 시작
- 잡힌 적에게 아군이 포커스 → 빠른 처치

### 교전 포인트
- 이니시 타이밍이 모든 것. 좋은 이니시 한 번이 교전을 결정
- 궁극기 빗나가면 즉시 후퇴. 절대 쿨 없이 싸우지 않음
- 아군과의 거리감 유지. 혼자 너무 앞서가면 1:3 당함

### 실수 패턴
- 욕심부려서 2명 이상 잡으려다 타이밍 놓침
- 궁극기 없이 어정쩡하게 들어감
- 아군 서포터/딜러의 위치 확인 안 하고 이니시

## 이바

**역할:** 브루저 / 2선
**장인초대석:** 25.04.21

### 집단전 역할
- 근접 브루저로 적 후방 침투 또는 전방 전투
- 내구도와 딜을 겸비. 교전 지속력이 높음

### 교전 포인트
- 진입 후 생존력이 핵심. 들어간 후 살아서 나올 수 있는지 계산
- 적 딜러를 노리되, 불가능하면 앞에 있는 적을 처리
- 쿨타임 관리: 이동기를 공격용으로만 쓰면 퇴각이 불가능

### 실수 패턴
- 이동기를 전부 공격에 사용 → 빠져나올 수 없음
- 적 탱커와 1:1 하면서 시간 낭비
- 팀과 동떨어져서 혼자 진입

## 아드리아나

**역할:** 원거리 딜러 / 2~3선
**장인초대석:** 25.04.25

### 집단전 역할
- 광역 딜러. 화염으로 범위 데미지를 넣어서 다수를 동시에 공격
- 존 컨트롤: 화염 영역을 깔아서 적의 진입로를 제한

### 교전 포인트
- 스킬 배치가 핵심. 적이 모여있을 때 광역기로 최대 효율
- 궁극기는 적이 모여있는 순간에 사용. 한 명에게 쓰면 낭비
- 2선에서 공격적으로 플레이할 수 있지만 생존에 주의

### 실수 패턴
- 광역기를 적 1명에게만 사용
- 화염 영역을 아군이 도망가야 하는 곳에 배치
- 사거리를 잘못 계산해서 적에게 잡힘

## 히스이

**역할:** 브루저 / 1~2선
**장인초대석:** 25.05.13, 초운

### 집단전 역할
- 진입력이 높은 브루저. 적 후방까지 침투 가능
- 처치 후 리셋(초기화)으로 연속 전투 가능

### 교전 포인트
- 진입 시 "처치 가능한 대상"을 먼저 확인. 킬 확보가 리셋의 조건
- 리셋 후 다음 타겟으로 전환. 한 명에게 붙잡히면 안 됨
- 쿨타임 계산: 진입기가 쿨이면 기다리기

### 실수 패턴
- 처치 불가능한 대상에게 진입 → 리셋 실패 → 사망
- 너무 깊이 들어가서 아군 지원 범위 밖
- 궁극기를 섣불리 사용

## 버니스

**역할:** 원거리 딜러 / 3선
**장인초대석:** 25.05.21, 하늘의향기

### 집단전 역할
- 안전한 거리에서 지속 딜. 평타 중심의 DPS
- 상대 진입을 자체 CC로 끊는 자기 보호 능력 보유

- 딜을 넣을 수 있는 가장 가까운 안전한 대상을 공격

### 실수 패턴
- 자기 보호 스킬을 먼저 사용 → 적 어쌔신 진입 시 무방비
- 킬을 쫓아서 전방으로 나감 → 잡힘
- 팀과 너무 멀어짐

## 실비아

**역할:** 브루저 / 2선
**장인초대석:** 25.06.18, 실버실비아

- 변환 중 CC 맞아서 죽음
- 아군 없이 혼자 진입

## 니아

**역할:** 서포터 / 브루저 겸용 / 2~3선
**장인초대석:** 25.11.20, 스칼렛시스터
**꿀팁 영상:** 25.05.17

### 집단전 역할
- 서포터와 브루저 사이의 유연한 역할. 빌드에 따라 달라짐
- 힐/쉴드로 아군 보호 + 자체 전투력으로 교전 기여

### 교전 포인트
- 방관 트리가 효율적 (네브짱 니아 꿀팁 영상 기준)
- 조합에 따라 서포터로 플레이할지, 브루저로 플레이할지 결정
- "삼선만 아니면 상관없다" → 니아는 1~2선 어디서든 유연하게 플레이 가능

### 실수 패턴
- 역할을 명확히 정하지 않고 애매하게 플레이
- 서포터인데 너무 앞에 나감 / 브루저인데 뒤에서만 힐
- 궁극기 타이밍 실수

## 데비·마를렌

**역할:** 듀얼 딜러 / 2~3선
**공략 영상:** 25.07.16 (시즌 8 공략)

### 집단전 역할
- 두 캐릭터를 전환하면서 플레이하는 독특한 스타일
- 상황에 따라 근접/원거리를 전환

### 교전 포인트
- 전환 타이밍이 핵심. 잘못된 타이밍에 전환하면 무방비
- 각 형태의 강점을 이해하고 상황에 맞게 사용
- 조합 내에서 자신의 역할을 명확히 하고 전환

## 공통 주의사항

### 모든 캐릭터에 해당하는 원칙

1. **죽지 마라** - 죽으면 어떤 캐릭터든 가치가 0
2. **팀과 함께** - 혼자 나가면 1:3으로 죽음
3. **쿨타임 확인** - 핵심 스킬이 쿨타임이면 교전을 미룸
4. **구도 판단** - 불리한 싸움은 피하는 것이 실력
5. **선입력** - 반응이 아닌 예측으로 플레이. 선입력이 상급자의 기본
