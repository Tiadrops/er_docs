## ウィリアム

**役割:** 遠距離ディーラー（特殊型）
**匠招待席:** 25.02.12〜13, 둔둔빵줘라

### 集団戦での役割
- 遠距離からダメージを出す特殊な遠距離キャリー
- 死亡後もダメージを出せるのが強み（設置物・持続ダメージ系）
- ライン維持も担える万能型。ディーラーとしての火力とライン抑えを両立

### 交戦ポイント
- ブルーザー構成相手にはウルトを退路側に設置して敵の進入を阻む
- 敵が突っ込んでくる構成の場合、前方ではなく退路にウルトを敷く
- ポジション取りの自由度が高い（遠距離なのでポジションを取られにくい）

### ミスパターン
- 操作難度が高いキャラなので、ミスると自分にできることが少なくなる
- ポジション管理を怠ると近接キャラに詰められる

## セリン

**役割:** サポーター / 3線
**匠招待席:** 25.02.15, 송하랑

### 集団戦での役割
- 3線で味方ディーラーを保護しながらヒールとシールドを提供
- CCで敵の進入を妨害。敵ブルーザー/アサシンが味方ディーラーを狙えば即座にCC

### 交戦ポイント
- ヒール/シールドのタイミングが全て。0.5秒の差で味方が生きるか死ぬか
- ウルトは「救う」用に取っておくのが基本。攻撃用に先に使わないこと
- ポジショニング: 常にディーラーの近くに位置。ディーラーから離れるとサポーターの価値は0

### ミスパターン
- ディーラーを置いて前に出る
- ヒールを早く使いすぎる (敵が本格的な交戦前にヒールが尽きる)
- CCを空中に使用

## タジア

**役割:** 遠距離ディーラー / 3線
**匠招待席:** 25.02.18, Cherish

### 集団戦での役割
- 安全な距離から持続ダメージ。最も近い安全な対象を攻撃
- 生存がすなわちダメージ。「死んだディーラーのDPSは0」

### 交戦ポイント
- 射程管理が核心。敵の進入射程外でダメージ
- ウルトで敵のイニシを切るか、逃走する敵を仕上げ
- ポジショニング: 1線の後ろに常に位置。前方に出ない

### ミスパターン
- キル欲で射程内に入る → 捕まる
- タンカーを殴って時間を消費
- 味方が交戦中なのに遠くで見物

## キャシー

**役割:** 暗器ディーラー / 2〜3線
**匠招待席:** 25.02.26, 캐시맨

### 集団戦での役割
- 遠距離牽制 + 瞬間バーストダメージ。暗器の射程を活用したポークプレイ
- 敵の体力を削った後に味方が仕上げ

### 交戦ポイント
- フルコンボ命中時に一人蒸発可能。「コンボ精度 = キャシーの価値」
- コンボ失敗時は無理せず引いてクールダウンを待つ
- 位置取りが重要。交戦開始前に良い角度を確保

### ミスパターン
- コンボ外した後も近接戦を試みる → 耐久力不足で死亡
- チームと離れすぎてプレイ → 合流が遅い
- 視野なしで移動 → 敵アサシンに捕まる

## ナタポン

**役割:** ブルーザー / 1〜2線
**匠招待席:** 25.04.11, 엄빠TV

### 集団戦での役割
- ヌンチャクのCCとダメージで前方で戦う。敵を拘束しながらダメージ
- イニシも可能だが、1線タンカーがいれば2線で後続投入がより効率的

### 交戦ポイント
- CC連携が核心。スキル順序を事前に計画して敵を最大限長く拘束
- ウルトは複数人に当てられるタイミングで使用
- 耐久力とダメージのバランス: 状況に応じてタンキーかダメージビルドに切り替え

### ミスパターン
- CCを一人だけに集中 → 残りの敵が自由にダメージ
- ウルトを1人にだけ使用 → 価値の無駄
- 後方を無視して前方だけ見て味方ディーラーが倒される

## ルク

**役割:** タンカー / 1線イニシエーター
**匠招待席:** 25.04.16, Karmis

### 集団戦での役割
- 強力なイニシエート。ウルトで敵核心を捕まえて交戦開始
- 捕まった敵に味方がフォーカス → 素早い処置

### 交戦ポイント
- イニシタイミングが全て。良いイニシ一発が交戦を決定
- ウルト外したら即座に後退。絶対にクールなしで戦わない
- 味方との距離感維持。一人で先行しすぎると1:3にやられる

### ミスパターン
- 欲張って2人以上捕まえようとしてタイミングを逃す
- ウルトなしで中途半端に入る
- 味方サポーター/ディーラーの位置確認せずにイニシ

## イバ

**役割:** ブルーザー / 2線
**匠招待席:** 25.04.21

### 集団戦での役割
- 近接ブルーザーとして敵後方浸透または前方戦闘
- 耐久力とダメージを兼備。交戦持続力が高い

### 交戦ポイント
- 進入後の生存力が核心。入った後に生きて出られるか計算
- 敵ディーラーを狙うが、不可能なら目の前の敵を処理
- クールダウン管理: 移動技を攻撃用だけに使うと退却不可能

### ミスパターン
- 移動技を全て攻撃に使用 → 抜け出せない
- 敵タンカーと1:1して時間浪費
- チームと離れて一人で進入

## アドリアナ

**役割:** 遠距離ディーラー / 2〜3線
**匠招待席:** 25.04.25

### 集団戦での役割
- 広域ディーラー。炎で範囲ダメージを入れて複数を同時に攻撃
- ゾーンコントロール: 炎の領域を敷いて敵の進入路を制限

### 交戦ポイント
- スキル配置が核心。敵が集まっている時に広域技で最大効率
- ウルトは敵が集まっている瞬間に使用。一人に使うと無駄
- 2線で攻撃的にプレイできるが生存に注意

### ミスパターン
- 広域技を敵1人にだけ使用
- 炎の領域を味方が逃げるべき場所に配置
- 射程を間違えて敵に捕まる

## ヒスイ

**役割:** ブルーザー / 1〜2線
**匠招待席:** 25.05.13, 초운

### 集団戦での役割
- 進入力が高いブルーザー。敵後方まで浸透可能
- 処置後のリセット(初期化)で連続戦闘が可能

### 交戦ポイント
- 進入時に「処置可能な対象」をまず確認。キル確保がリセットの条件
- リセット後に次のターゲットに転換。一人に捕まってはいけない
- クールダウン計算: 進入技がクール中なら待機

### ミスパターン
- 処置不可能な対象に進入 → リセット失敗 → 死亡
- 深く入りすぎて味方支援範囲外
- ウルトを性急に使用

## バニス

**役割:** 遠距離ディーラー / 3線
**匠招待席:** 25.05.21, 하늘의향기

### 集団戦での役割
- 安全な距離から持続ダメージ。通常攻撃中心のDPS
- 相手の進入を自己CCで切る自己保護能力を保有

### 交戦ポイント
- ポジショニングが核心。敵の進入射程外でダメージ
- 自己保護スキルは温存。敵が進入する前に使ってはいけない
- ダメージを入れられる最も近い安全な対象を攻撃

### ミスパターン
- 自己保護スキルを先に使用 → 敵アサシン進入時に無防備
- キルを追って前方に出る → 捕まる
- チームと離れすぎる

## ニア

**役割:** サポーター / ブルーザー兼用 / 2〜3線
**匠招待席:** 25.11.20, 스칼렛시스터
**Tips動画:** 25.05.17

### 集団戦での役割
- サポーターとブルーザーの間の柔軟な役割。ビルドにより変わる
- ヒール/シールドで味方保護 + 自己戦闘力で交戦に貢献

### 交戦ポイント
- 傍観ツリーが効率的 (ネブジャン・ニアTips動画基準)
- 構成に応じてサポーターとしてプレイするか、ブルーザーとしてプレイするか決定
- 「3線でさえなければ問題ない」→ ニアは1〜2線どこでも柔軟にプレイ可能

### ミスパターン
- 役割を明確に定めず曖昧にプレイ
- サポーターなのに前に出すぎ / ブルーザーなのに後ろでヒールだけ
- ウルトのタイミングミス

## デビ・マーリン

**役割:** デュアルディーラー / 2〜3線
**攻略動画:** 25.07.16 (シーズン8攻略)

### 集団戦での役割
- 二つのキャラクターを切り替えながらプレイする独特なスタイル

## 共通の注意事項

### 全キャラクターに共通する原則

1. **死ぬな** - 死んだらどのキャラでも価値は0
2. **チームと一緒に** - 一人で出たら1:3で死ぬ
3. **クールダウン確認** - 核心スキルがクールダウン中なら交戦を先延ばし
4. **構図判断** - 不利な戦いを避けるのも実力
5. **先行入力** - 反応ではなく予測でプレイ。先行入力が上級者の基本
