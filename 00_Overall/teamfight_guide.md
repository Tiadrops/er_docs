## 1. 役割・ポジション定義

### ライン制 (1線/2線/3線)

スクワッド集団戦では各チームメンバーが「何線に立つか」で役割が分かれる。

| ライン | 位置 | 役割 | 代表キャラタイプ |
|--------|------|------|-----------------|
| **1線** (フロント) | 敵に最も近い最前線 | 敵の攻撃を吸収し進入路を確保。イニシエートまたはアグロ誘導 | タンカー、ブルーザー (マグヌス、レオン、ウィリアム、エキオン) |
| **2線** (ミドル) | 1線の後ろ、3線の前 | 1線を支援しつつダメージを入れる中間ポジション。状況に応じて1線のように進入するか、3線を保護 | ブルーザー、近接ディーラー (カミロ、ジャッキー、イバ、アドリアナ) |
| **3線** (バック) | チームの最後方 | 安全な距離から持続ダメージまたはヒール/サポートを提供。絶対に先に進入しない | 遠距離ディーラー、サポーター (アヤ、ナディン、エマ、ユミン) |

**核心原則:**
- ラインが崩壊すると集団戦は負ける。1線が溶ければ3線が即座に露出する
- ラインは固定ではない。状況に応じて流動的に動く必要がある
- 2線の判断力が最も重要。進入タイミング、保護への転換を瞬時に判断する必要がある

**根拠:** ネブジャンの視聴者リプレイで最も多く指摘されるポイントが「ラインを無視して3線が先に入る」または「1線が深く入りすぎてチームがついて行けない」。

---

### 役割分類

#### タンカー (T)
- **目的:** 敵の攻撃を吸収しCCで敵を拘束
- **判断基準:** 味方ディーラーがダメージを入れられる時間と空間を作ること
- **ミスパターン:** 無闇に突進 → チームがついて来れず一人で死亡

#### ブルーザー (B)
- **目的:** 1〜2線でダメージと耐久力を兼備。交戦の核心戦闘力
- **判断基準:** 進入後に処置可能かどうか、退却可能かどうかを計算
- **ミスパターン:** キル欲 → CCやウルトがない状態で進入 → 逆スノーボール

#### ディーラー・AD/SD (D)
- **目的:** 持続的に高いダメージを出力
- **判断基準:** 生存＝ダメージ。死んだらダメージは0
- **ミスパターン:** 射程外でダメージを入れないか、逆に前に出すぎて捕まる

#### サポーター (S)
- **目的:** 味方維持 (ヒール、シールド、CC)
- **判断基準:** 味方ディーラーが生きていれば勝つ。ディーラー保護が最優先
- **ミスパターン:** ヒールタイミングの失敗 (早すぎるヒール → 敵がヒール待ちで進入 / 遅すぎるヒール → 味方死亡)

## 2. 集団戦のフェーズ

集団戦は4段階で進行する。

### フェーズ1: 対峙 (Pre-Fight)

交戦前にお互いの位置を取る段階。

**ポイント:**
- 視野確保が優先。相手の位置がわからなければ不利な交戦が始まる
- アイテム完成度とクールダウンを確認。核心スキルがクールダウン中なら交戦を先延ばしにするのが正解
- 構成把握: 相手が突進構成なら距離を維持、牽制構成なら積極的に距離を詰める
- **相手のウルト有無**を把握するのが核心。ウルトのないチーム相手には積極的に交戦

**根拠:** ネブジャンがリプレイで繰り返し強調すること：「なぜウルトないのに戦いを仕掛けた？」/「視野なしで入ったら3:3じゃなくて1:3になる」

---

### フェーズ2: イニシエート (Initiate)

一方が戦闘を開始する瞬間。

**ポイント:**
- イニシ ＝ 核心CCの命中。CCを外したらイニシ失敗 → リセットすべき
- 「イニシ失敗 ＝ 後退」という原則を必ず覚える。失敗したイニシについて行くと全滅
- イニシを受ける側は**カウンターイニシ**または**ディスエンゲージ**のどちらかを選択
- 良いイニシの条件: ① チームがついて来れる位置 ② 核心対象にCC命中 ③ 味方クールダウン確認

**イニシ判断基準:**
| 状況 | 判断 |
|------|------|
| 敵1人が孤立 | ✅ 積極的に進入 (3:2誘導) |
| 敵の核心クールダウン使用後 | ✅ すぐに進入 |
| 味方1人が瀕死(体力不足) | ❌ 無理せず後退 |
| 視野確保なし | ❌ 進入禁止 |
| 敵がオブジェクト進行中 | ✅ 状況を見て進入 (体力消耗した状態) |

**根拠:** ネブジャンの視聴者リプレイで「これイニシ失敗したのになぜついて行く？」/「敵のウルト抜けた時になぜ入らない？」というフィードバックが最も頻度が高い。

---

### フェーズ3: 交戦 (Main Fight)

本格的な戦闘。スキル交換、ダメージトレード、フォーカスが行われる核心段階。

**ポイント:**
- **フォーカス:** 一人を集中して素早く処置 → 数的優位を確保
- **ダメージトレード意識:** 「自分が入れたダメージ > 自分が受けたダメージ」の状態を維持
- **クールダウン管理:** 核心スキルは節約して決定的瞬間に使用
- **アグロピンポン:** 敵のターゲットが一人に固定されたらその人が一旦引き、別の人がアグロを引き受ける。これを繰り返す

**フォーカス優先順位:**
1. 体力が低い敵 (確定キル可能)
2. サポーター (ヒール遮断 → 残りが溶ける)
3. 遠距離ディーラー (DPS遮断)
4. 1線タンカー (最後。タンカーを先に殴るのは非効率)

**ただし状況に応じて流動的に変わる。** 進入してきた敵ディーラーが目の前にいればタンカーを無視してディーラーを倒すのが正解。

**根拠:** 「タンカーなぜ殴ってるの」/「サポーター先に倒せば残りは勝手に溶ける」 - ネブジャンのリプレイフィードバックでフォーカスミスの指摘が最も多い。

---

### フェーズ4: クリーンアップ (Cleanup)

交戦結果に応じた仕上げ。

**勝った時:**
- 深追いしない。他チームが漁夫の利を狙っている可能性あり
- 体力/アイテム整理を優先
- オブジェクト(ウィクライン等)の確保を検討

**負けた時:**
- 素早く判断して後退。「もう一人倒せそうだけど…」→ 全滅の原因
- 生き残った人数で最大限時間を稼ぐ

**根拠:** 「なぜ追いかける？体力もないのに」/「負けた時は素早く退くべき、ずるずる引くと全滅」 - ネブジャンが繰り返し強調する後退判断。

## 3. フェーズ別・役割別の目標

### 対峙フェーズ (Pre-Fight)

| 役割 | 目標 |
|------|------|
| タンカー (1線) | 前方で視野確保、敵の動き観察、無理な牽制禁止 |
| ブルーザー (2線) | 1線付近で待機、進入機会を探索、必要時に3線保護へ転換 |
| ディーラー (3線) | 安全な位置を確保、敵イニシ射程外で待機 |
| サポーター (3線) | 味方体力管理、視野確保補助、敵イニシに備えてCC/シールド準備 |

### イニシフェーズ (Initiate)

| 役割 | 目標 |
|------|------|
| タンカー (1線) | 敵核心対象にCC命中 → 交戦開始。または敵イニシ吸収 |
| ブルーザー (2線) | イニシに合わせて即座に後続投入。または敵カウンターイニシ対応 |
| ディーラー (3線) | イニシに合わせてダメージ開始。まだ前方に出ない |
| サポーター (3線) | イニシする味方にシールド/バフ。敵CCに対する解除準備 |

### 交戦フェーズ (Main Fight)

| 役割 | 目標 |
|------|------|
| タンカー (1線) | 敵ディーラーに圧迫、味方ディーラーを狙う敵を遮断、CC連続使用 |
| ブルーザー (2線) | 敵後方浸透または敵進入遮断。処置可能な対象に集中 |
| ディーラー (3線) | 最も近い安全な対象にダメージ。生存が最優先 (死んだらダメージ = 0) |
| サポーター (3線) | 味方ディーラー保護、ヒール/シールド維持、敵にCCで妨害 |

### クリーンアップフェーズ (Cleanup)

| 役割 | 目標 |
|------|------|
| タンカー (1線) | 逃走する敵を追撃CC。または味方後退を援護 |
| ブルーザー (2線) | 逃走する敵を仕上げ。味方が危険なら保護に転換 |
| ディーラー (3線) | 安全に追撃ダメージ。無理な追撃禁止 |
| サポーター (3線) | 味方体力回復。追撃可能かどうかの判断を補助 |

## 4. 核心コンセプト詳細

### 4.1 ダメージトレード (딜교)

**定義:** 敵とダメージを交換すること。「自分が入れたダメージが受けたダメージより多ければ勝利したトレード。」

**原則:**
- スキル命中後すぐに引く → 「ヒット＆アウェイ」がトレードの基本
- クールダウンが戻る前に再び入らない
- 相手がスキルを先に使った後に入れば一方的なトレードが可能
- 回復手段(ヒール、ポーション)がある側がトレードで有利

**ミスパターン:**
- スキル外したのに戦い続ける → 一方的に殴られるだけ
- フルコンボ入れて引くべきなのに残る → クールダウンの隙に反撃される
- 体力劣勢でトレードを試みる → 死亡

**根拠:** ネブジャンのリプレイで「トレードもう負けてるから引くべき」/「クールダウン空いてるのになぜまだ戦ってる？」

---

### 4.2 アグロ管理

**定義:** 敵の攻撃対象(アグロ)を意図的に誘導または分散させること。

**アグロピンポン:**
1. Aが敵のアグロを引いて後退
2. 敵がAを追う間にBが後ろからダメージ
3. 敵がBに転換するとAが再び進入
4. この繰り返しにより敵はダメージをまともに入れられず一方的にやられる

**核心:** アグロを引く時は「死なない程度に」耐える。アグロ誘導して死んだら逆効果。

**根拠:** ネブジャンの集団戦分析で「アグロを一人で全部食べちゃダメ、交互に引くべき」という概念を頻繁に説明。

---

### 4.3 先行入力 (선입력)

**定義:** スキルの発動を事前に入力し、状況発生時に即座に出るようにする技術。

**活用:**
- ブッシュ(草むら)対峙時: 敵が入ってくる瞬間に即座にCC → 先行入力したスキルがすぐ命中
- 敵接近予想時: ムーブしながらスキルキーを事前に準備 → 射程に入った瞬間すぐ発動
- Q → Wコンボ: Qが命中する瞬間にWを先行入力 → 最小ディレイで連携

**ミスパターン:**
- 先行入力なしで反応だけのプレイ → 常に遅れる
- 先行入力を外れた場所にする → クールダウン無駄

**根拠:** ネブジャンの動画タイトルにも「先行入力」が頻繁に登場。「先行入力で確定で当てるものだ」 - 先行入力は上級プレイの基本として強調。

---

### 4.4 構図判断 (交戦構図)

**定義:** 交戦前に「この戦いをすべきか？」を判断すること。

**有利な構図:**
- 数的優位 (3:2 または 3:1 状況)
- アイテム完成度の優位
- 核心ウルト保有 vs 敵ウルト不在
- オブジェクト周辺で敵が体力消耗した状態

**不利な構図:**
- 数的劣勢
- アイテム未完成 (核心アイテム1つ差は大きい)
- 敵が防御有利な地形を占拠
- 味方の体力/クールダウンが不完全

**判断の公式:** 「この戦いをして勝てるか？」→ Yes: 交戦 / No: 後退またはオブジェクト放棄

**根拠:** ネブジャンが最も多く言うことの一つ：「これは戦うべきじゃない」/「なぜ不利な戦いをする？」 - 戦わない判断も実力だという点を強調。

---

### 4.5 構成別戦略

#### 突進構成 (ダイブコンプ)
- **特徴:** CCと進入力が強いキャラクター中心
- **戦略:** 素早くイニシ → 敵核心を処置 → 数的優位で仕上げ
- **弱点:** イニシ失敗時に後退が難しい。牽制/カイティング構成に弱い

#### 牽制構成 (ポークコンプ)
- **特徴:** 遠距離牽制力が高いキャラクター中心
- **戦略:** 距離を維持しながらトレード → 敵体力を削った後に仕上げ進入
- **弱点:** 強制交戦(突進)にやられると脱出が難しい

#### 保護構成 (ピールコンプ)
- **特徴:** ディーラー1人 + 保護2人
- **戦略:** ディーラーを最後まで生かしながらディーラーが全ダメージを担当
- **弱点:** ディーラーが先に倒されたら終わり。ディーラー依存度が非常に高い

**根拠:** ネブジャンの匠招待席で各キャラクターの達人が自分の構成運用法を説明する際にこのような分類が頻繁に使用される。
