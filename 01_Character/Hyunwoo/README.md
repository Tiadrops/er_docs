## 翻訳方針メモ

- **キャラ名**は `99_Scripts/translation/ko_ja_glossary_table.md` に従う（ヒョヌ／ジャッキー／ナディン／ジャヒル等）。
- **アイテム略称**（朱雀／ブルド／オアム／ミトゥッ／天高／ヘルメス／芭蕉扇 等）は韓国ER独自の略語が多く、定訳が無いものは韓国読み準拠でカタカナ化。
- **コンボ表記**（EQ평D평 等）はそのまま記号で残す（`EQ→平→D→平`）。
- **シーズン依存の情報**（特に2021年攻略の装備優先順位・相性表）は、現環境では既に陳腐化している可能性があるため、**戦闘思想・運用ロジック**を抽出して読むのが推奨。

## キーポイント抽出（両攻略の交差点）

両者は時期もスタイルも異なるが、**ヒョヌの核となる戦闘原則**で一致している。

### 1. 「ピンポン」交戦観
- 1往復で決着しない。**入る→押し込む→引く→次のクールで再進入**のリピート。
- 2023年攻略：「**入って必ず2〜3回は歩いて出てこなければならない**」
- 2021年攻略：「**EQ→平→D→平 → 退き → W で噛む → 追ノ**」のサイクル

### 2. 装備ハンガーとしてのヒョヌ
- 2021年攻略：「**ヒョヌは装備のハンガーである**」（=拾えるガチャ装備は基本全部拾う）
- 純粋体格＝レジェンダリ装備の効率が高いキャラなので、装備差を作れば構図がひっくり返る。

### 3. 高ランク帯の鍵は「マクロ」
- 2023年攻略の半分以上はヒョヌ固有の話ではなく、**チーム検証・3位確保・強チーム回避・C/D役**といったスクワッド構造論。
- ヒョヌは「強い時に殴れて弱い時に逃げる」キャラ性の都合で、**戦う相手を選ぶ判断**が勝率に直結する。
