## まとめ（要点）

### ビルド大前提
- 現環境のシュリンは**防貫／ディルタンク／AAビルド**のいずれを選んでも性能を発揮する。
- 本攻略は**「脆弱真刃」防貫型**の実戦テンプレート。

### ルート：**主・学・洋（주학양）**＝ ガソリンスタンド→学校→弓道場
- 動線が非常に短く、**1分30秒残して装備完成**できる
- 弓道場から **주（ガソスタ）・학（学校）・호（ホテル）の3方向**へ狼狩りに伸びられる
- 脆弱真刃ビルドなので、**弓道場での 1on1 は、マーカスのような硬すぎるタンクが来ない限り、ほぼ確実に勝てる**

### 特性：**「狩りの戦慄」（사냥의 전율）**
- 狩猟速度が圧倒的に速い。**今回パッチで野生動物被ダメ 18%→20% に上方修正**
- `Q→E→AA→E` で**熊・変異野犬ですら高速で処理**でき、クレジット／武器熟練度／動線短縮に寄与
- 混沌特性の「鉄甲弾」のようなダメージ特性を取ることも可能だが、**既に火力が十分なのでオーバーキル**と判断

### アイテム：**ミラージュ（Mirage）採用、武器をガチャしない理由**
- **スキル加速 25（=20%）**を満たすと `Q→E→AA` で E がすぐクールに戻る数値
- なので**最低 20% のスキル加速**を目標
- 防貫ビルドのため**紫武器（Epic）と黄武器（Legendary）の攻撃力差はほぼ無し**（精々 1 程度）
- **隕石武器の流星剣のパッシブは唯一悪くない**が、**タダ隕石で手に入った場合以外**は装備を整えてから血武器コースで OK

### 装備順
**タクティカルアーマー → トワイライト → ソガチェ[^1] → ミラージュ → 血武器**

[^1]: 서가체 (ソガチェ) — 防具系装備の略称。文脈から防具枠と思われるが正式名称は未確認。

## スキルコンボ

### 基本コンボ：`Q→E→AA / E→AA`
- 射程が短いので**イニシエート用には不向き**
- **交戦が継続している中で使う基本技**
<video src="./_sources/02/Xuelin_QEAAEAA.mp4" controls width="600"></video>

### エンゲージコンボ：`Q→D→E` または `D→Q→E→AA / E→AA`
- `Q→D→E`：**相手が進入しようとしているムービング時**
- `D→Q→E`：**射程内に入った相手に先制でイニシエートする時**
- **レイピアマスタリを活用した `D→Q→E` 進入の方が確実**なので、こちらを推奨
<video src="./_sources/02/Xuelin_QDEAAEAA.mp4" controls width="600"></video>

### 実戦頻出メインコンボ：
**`Q→D→E（または D→Q→E）→ R → 領域外へ少しずつ動きながら → AA→W→E→AA`**

- **実戦で最も頻繁に使うコンボ**
- 剣の回収は**領域の外に出ないと発動しない**ので、**少しずつ動いて E を領域外まで出す**
<video src="./_sources/02/Xuelin_QDEAAR.mp4" controls width="600"></video>

### 応用コンボ：
**`1線に対し D で乗り → 後衛ディーラーへ Q→E→R→AA`**
- `Q→E→R→AA` まで終わった後、**状況次第で W を使うか、追跡して殴り続けるか**を判断
<video src="./_sources/02/Xuelin_QDEAAR_advance.mp4.mp4" controls width="600"></video>

## 実戦シチュエーション

### vs アレックスが1線
**`D→レイピアマスタリ`** で接近
→ `Q→E` の後、**アレックスの分身挑発に対応するため W**
→ その次に **R**
<video src="./_sources/02/Xuelin_fight1.mp4" controls width="600"></video>

### vs リオのノックバック
**`Q→E→R→AA` の後、W でリオのノックバックをカウンター**
→ その後、前に少しずつ動きながら**円の外に E で抜ける**
<video src="./_sources/02/Xuelin_fight2.mp4" controls width="600"></video>

### vs カティヤ
**CC でカティヤの位置を確認 → 車の裏から強襲**
<video src="./_sources/02/Xuelin_fight3.mp4" controls width="600"></video>

### 集団戦のフォーカス優先順位
**1順位はディーラー**
カティヤの位置を確認したら、**即座に D マスタリで突っ込んでカティヤをフォーカス**
<video src="./_sources/02/Xuelin_fight4.mp4" controls width="600"></video>

### 平時の交戦
**ヒット＆ランを軸に距離を保って戦う**
**通常攻撃は「3スタック発動 AA」でない限り、わざわざ打つ必要はない**

## 訳者メモ

### 01番との比較

| 項目 | 01番（イレブンでも理解できる） | 02番（脆弱真刃・防貫テンプレ） |
|---|---|---|
| 著者の立場 | イター帯 / 教育的記述 | シーズン8 攻略大会出品 / 圧縮テンプレ |
| ルート | **ホヨン（42765）** ホテル→池 | **主学洋（주학양）** ガソスタ→学校→弓道場 |
| 特性方針 | 不屈（バグ回避） | **狩りの戦慄**（混沌） |
| 装備路線 | ヘリックス→ジョワユーズ→オメルタ→ブレイドブーツ→スパークシールド | **タクアー→トワイライト→ソガチェ→ミラージュ→血武器** |
| キーパラメータ | パッシブ3スタックの回転 | **スキル加速20%（Qイ平の E 即時クール）** |
| メインコンボ | `AA→Q→AA + AA→E→Q→E + AA` | `Q→D→E→R→AA→W→E→AA`（領域外への移動付き） |
| 教戦観 | 自分から先に飛び込む／フルコン投下 | **ヒット＆ラン中心、AAは3スタック時のみ** |

### 注目すべき点

1. **「現環境のシュリンは何を持っても機能する」**——著者は明言。01番のヘリックス路線も02番の防貫路線も成立する。
2. **AA を 3スタック発動時以外打たない**は01番と発想が違う。01番が**サイクル回転重視（パッシブ2回でCD回す）**なのに対し、02番は**距離維持と単発バースト重視**。
3. **キーアイテムが「ミラージュ」でスキル加速 20%**の閾値設計は01番に無い情報。`Q→E→AA→E` が即時に二回目に入れるかの分水嶺。
4. **D（戦術スキル）の使い方が中心**——`D→Q→E` / `D→レピアマスタリ` / `D→マスタリ→カティヤフォーカス` など、Dをトリガーとして全部のエンゲージを構築している。
5. **動線「주학양」**は短く、**弓道場での 1on1 が成立する**前提のビルドであることを思い出すと、**「マーカス級のタンクには勝てない」**の含意が大きい。
6. **「3スタック発動 AA 以外打つ必要なし」**——01番の AA 連打サイクルと真逆の哲学。**集団戦ではバースト一発投下→離脱→次サイクル**という運用と考えると整合する。
