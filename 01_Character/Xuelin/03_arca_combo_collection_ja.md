## 訳者メモ

### 02番との比較

| 項目 | 02番（脆弱真刃・防貫テンプレ） | 03番（コンボ集？） |
|---|---|---|
| 立場 | 攻略大会出品の完成テンプレ | 訓練場での試行錯誤メモ |
| 前提 | スキル加速 25（20%） | **スキル加速 35（25%）／Q5・E2** |
| 主コンボ | `Q→D→E→R→AA→W→E→AA` | `Q→D→E→R→AA→W→E→AA→Q`（**Q追加**） |
| 確実性 | 実戦想定 | 「実際使えるかわからん」 |

### 注目点

1. **`Q→E→AA→E→AA` は Q2 のバグ依存**——スタックが1個多く入る現バグでのみ成立。**バグ修正後は崩れる可能性**があるので採用判断に注意。
2. **スキル加速の閾値が 02番より高い**（20% → **25%**）。Q5/E2 のスキルレベルも前提なので、**中盤以降のコンボ集**と解釈できる。
3. **③ コンボは 02番の「実戦頻出メインコンボ」の延長**——02番が `Q→D→E→R→AA→W→E→AA` で終わるところを、03番は**最後に Q を1発追加**して締める。スキル加速 25% と Q5 の前提があれば、Q が間に合うらしい。
4. 「**領域の外に出る必要があるので、合間合間に動く**」は02番と同じ注意点。R の剣回収トリガが「領域外移動」である構造を理解していないと刺さらない。
